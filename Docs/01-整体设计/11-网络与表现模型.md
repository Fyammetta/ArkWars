# 11 网络与表现模型

> 边界与呈现：服务器权威的落地规则、复制形态、客户端世界如何被驱动、玩家输入如何上行、表现如何不反压规则。战斗系统不做客户端预测。
> 关联：各卷"复制可见"的落点集中在此；客户端相关约定全卷适用。

## 1. 职责边界

| 管 | 不管 |
|---|---|
| 权威边界与改状态门控 | 规则裁决本身（`02`~`09` 各自） |
| 复制策略与 OnRep 分工 | 界面/动效具体实现（内容侧） |
| 客户端输入上行协议与校验 | 什么输入合法（`10` 校验在先） |
| 表现队列与 GameplayCue | 服务器结算是否等动画（绝不等） |

## 2. 权威边界（铁律）

| 类别 | 服务器 | 客户端 |
|---|---|---|
| 规则裁决（回合/时机/交易/账本/技能激活） | 唯一执行者 | 不执行 |
| 状态修改（阶段、区域、属性、状态实例） | 唯一写入者 | 只读复制值 |
| 流程推进（`Advance`/出队/开窗） | 唯一驱动者 | 无任何流程任务 |
| 输入裁决（发动/选目标/响应） | 校验后生效 | 提交意图 |
| 表现（动画/数字/牌飞） | 只发信号 | 本地播放 |

落地铁律：
- 所有改状态入口带 `IsRunningOnServer()`/`HasAuthority` 门控（现状已按此修正，持续审计）。
- 子系统创建条件按 `GetNetMode()`（`!= NM_Standalone`），专用服务器同样可用；权威改动统一走门控。

## 3. 客户端世界由三类输入驱动

```
① 复制属性   阶段/顺位/各区域(独立 OnRep)/属性值 —— 世界长什么样
② 事实通知   委托/Notify（阶段进入、牌已移动、伤害已结算）—— 世界刚发生什么
③ GameplayCue/表现信号  —— 瞬时演出（伤害数字、翻牌、牌飞行）
```

- 客户端**不订阅任何查询时机**，不接收窗口事件本体；只收"你有响应权 + 候选集"的表现形态。
- 阶段表现走复制 + RepNotify：客户端看到的是服务器状态的照片流，不自己推演。

## 4. 表现队列（规则与表现的唯一缓冲）

```
服务器结算快于表现 → 表现请求入队，本地顺序播放，追不上就攒
服务器结算慢于表现 → 队列空，等数据到达再播下一段
```

- 队列只在客户端；满/慢不影响服务器继续结算（无反压）。
- 表现请求带**可断言的排序依据**（阶段/交易序号或事件序号），回放与断线重连可据此对齐。

## 5. 玩家输入上行（交互层通道）

```
服务器开窗/开候选 → 客户端弹交互 → ServerRPC 提交
服务器按 10 §5 校验 → 通过才落地
```

- 客户端到服务器单向上行，无服务器主动推输入需求。
- 反外挂：服务器侧一切以**服务器持有状态**为准（候选集重算），不信任客户端自报的合法/非法。

## 6. 网络模式与部署

| 模式 | 支持 |
|---|---|
| 独立服务器 / Listen | 是（子系统 `GetNetMode()` 创建） |
| Standalone 单机调试 | 流程门控放行（`IsRunningOnServer` 真），便于无网调试 |
| 分房间/大厅 | 对局用 GameState 承载，与既有 GameMode/PlayerController 分层一致 |

## 7. 回放与指令队列（可选收尾，交易即数据源）

- 交易队列 + 时机/通知事件天然是**指令流**：记录"入队交易 + 窗口响应 + 收敛结果"即可回放，无需记录每帧状态。
- 回放与录像作为 P7 扩展，不做进引擎核心。

## 8. 与邻卷契约

| 本卷对外 | 契约 |
|---|---|
| 对 `02`：阶段事实 | OnRep/委托消费，无流程任务 |
| 对 `03`/`10`：窗口事件 | 客户端只收"表现形态"（候选/你有权响应），不参与裁决 |
| 对 `04`/`08`：交易/移动结果 | 经复制可见；服务器不等动画 |
| 对 `06`：状态表现 | 状态实例随属性/标签复制，Cue 出特效 |

## 9. 扩展点

- 新表现 → 加 Cue/表现信号 + 客户端队列项，服务器规则零改动。
- 新客户端交互 → 提交 RPC 加数据形状（校验不变）。
- 录播/观战 → 挂事件订阅器导出指令流，不侵入结算。

## 10. 落地与状态

| 项 | 现状 |
|---|---|
| 复制基础 | 区域 5 区 + 顺位/阶段复制与独立 OnRep ✅；属性复制 P4 起 |
| 表现队列 | 未落地（P7 或随首批 Cue 做最小形态） |
| 输入上行与校验 | 选择委托客户端侧已有；服务器校验随 `10` P3+ |
| 门控审计 | P0 收尾清单持续跟踪（组件创建、客户端 BeginPlay 双组件等） |
