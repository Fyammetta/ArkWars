## 4. 基线规约（全 P 阶段遵守，勿回退）

- 静态标签 = 原生 GameplayTag（`.cpp` `UE_DEFINE_GAMEPLAY_TAG`），禁用静态初始化期 `RequestGameplayTag`。
- 所有改状态入口 = `IsRunningOnServer()`/`HasAuthority` 门控；客户端零决策。
- 组件/管理器找宿主统一走"子系统单一入口"（`GetPhaseManager` 模式），不散落 `FindComponentByClass`。
- 日志英文 + 类别，名称取标签/枚举值，不硬编码字符串。
