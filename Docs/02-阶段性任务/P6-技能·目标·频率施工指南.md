> 本阶段**不做持续状态/多回合效果**（P7）；技能体异步等待（`UAbilityTask_WaitResponses`）本阶段引入。

## 2. 技能声明落地（卷 `09` §2/§4/§10）

- 激活方式**降维为标志组合**（卷 `09` §4 表）：

```cpp
// FSkillInfo —— 与 `09` §2 逐字一致的就地完整版（改声明字段先改 09 §2，再回抄本块）
struct FSkillInfo {
    FGameplayTag SkillTag;
    FGameplayTagContainer ListenTimings;

    bool bAutoOnTiming = false;      // 时机到达即自动（锁定/全自动被动）
    bool bAskFirst = false;          // 到达时机先询问（false + bAutoOnTiming = 全自动）
    bool bPlayerInitiated = false;   // 玩家主动输入触发（主动技）

    TSubclassOf<UGameplayAbility> AbilityBody;
    // 无技能级 ResponsePriority：次序 = 座次（开窗实时读），All/FirstOnly 同时发生无序（10 §2）

    // 频率（07 §4）：账本键族 + 上限（空键/0 = 不限）
    FGameplayTag FrequencyKey;
    int32 MaxUsesPerRound = 0;
    int32 MaxUsesPerGame = 0;
    bool bPerOwner = true;

    // 目标（05 §3.2）：目标规则数据资产（UTargetRuleData 完整定义见 05 附录；空 = 无目标限制）
    TSoftObjectPtr<UTargetRuleData> TargetRule;

    // 演化（09 §7）：原始声明引用（觉醒/修改产生副本）
    TObjectPtr<FSkillInfo> BaseSkill;
    int32 EvolutionGen = 0;
};
```

- 旧 `ESkillActivateType` 枚举值映射为**标志组合**（限定技=主动 + `MaxUsesPerGame=1` 等），枚举保留作编辑器便利，引擎分支一律查标志。
- 索引：`USkillManagerSubsystem` 时机 → 监听技能表；排序 = 座次（`ISeatLayout`，开窗实时读 `PhaseComponent`）**稳定排序**（同座多技能先注册先问，P3 §7 复查项闭环）；不设技能级 `ResponsePriority`（`10` §2）。
- 开窗预检接入真实条件：来源在场/状态许可/账本余量（`FrequencyLedger` 预检）等。

## 3. 频率账本（卷 `07` §3/§8）

- `FrequencyLedger`（挂流程子系统或独立 UObject）：`QueryUseAllowed/TryConsume/Release/ResetScope/GetUsed/GetRemaining`。
- 键命名空间 `{作用对象}×{族}×{周期}`；键解析器注册（含演化代次后缀）。
- 周期重置订阅 `02` 回合边界广播（`BroadcastRoundRefresh` 类事实）→ `ResetScope(Round)`。
- 接线：`09` 触发判定里 ① 询问前 `QueryUseAllowed` ② 激活时 `TryConsume` ③ 取消/防止 → `Release`（沿 `04` `Finish(false)` 防止链：不 Execute、族 `BroadcastFinish(false)` 广播取消/防止通知）；吞效果（`bNullified`）不回滚。
- 锁技/主动技都可带账本；`bPerOwner` 区分全局/个人。

## 4. 目标与距离（卷 `05` §2~§5/§8）

- `Targetable`/`TargetSet`/`FGameplayTagContext`/`EObjectPool`/`ITargetValidator`/`FTargetSpec`/`UTargetRuleData`/`ISeatLayout`/`IRangeModifierProvider` 的契约形状与成员全量定义见 `05` 卷附录（"语义层契约类型"与"ITargetValidator / UTargetRuleData"）；本阶段按附录落地 `Battle/Toolkits/` 语义层 + `ResolveTargets`/`IsValidTarget` 实现。
- 校验器注册表：存活/身份/区域/距离/状态/自定义；距离校验器经 `IRangeModifierProvider` 注入。
- `ISeatLayout` 环形座位实现 + `IRangeModifierProvider`（基础攻距 + 修正项注册）。
- 目标集锁定在使用/技能生效前；锁定后窗口期目标失效 → 走 `05` §2 失效传播（P6 先单层：失效即对该目标取消）。
- 玩家选择：选择来源接入 `10` §5 协议（候选下发 + ServerRPC 提交 + 服务端重算校验）。

## 5. 技能体与批量技能（卷 `09` §5/§6/§9）

- 引入 `UAbilityTask_WaitResponses`（服务器等待类，窗口内异步动作载体；开窗结构不变，见 P3 §3.6 备注）。
- **样板技能组**（内容侧，验证形状组合，禁止写成引擎逻辑）：
  1. 自动：受伤后恢复类（监听 `Notify.Damage.Applied`，事实订阅）；
  2. 询问主动：判定前跳过（自 P3 测试技迁为正式数据声明 + 技能体）；
  3. 限次：整局一次类主动技（`MaxUsesPerGame=1`）；
  4. 距离受限目标技（目标规则带距离校验器）；
  5. 演化技：到达条件 → 派生声明副本 +1 代次、新账本计数。
- 每例对应卷 `01` §6.2 五步法记录：挑形状→注册标签→写数据→写技能体→回填案例（各卷案例小节）。

## 6. 演化骨架（卷 `09` §7）

- 演化 = 派生声明副本（改监听/上限/目标/绑定技能体）→ 旧实例撤销、新实例 Grant → 账本换代次计数 → 事实通知"技能变化"（客户端刷新）。
- 引擎零"觉醒"概念；来源记录演化触发者。

## 7. 标签数据驱动合规（收口 P0 §3 余留 1）

- 卡种类/技能区域等**开放集**落到单个 GameplayTags 数据资产（挂 `DefaultGameplayTags.ini`）并登记；有限常量集保持原生标签。
- 内容技能全部用索引/数据路径，代码零硬编码卡名/技能名。

## 8. 验收

1. 五样板技能逐条成立：触发条件正确、询问/自动分流、限次生效且 `Release` 回滚正确、距离限制生效、演化后能力与计数正确。
2. 事实/查询通道分流正确（自动技走事实/查询不误）。
3. 目标锁定与失效：窗口期目标失效 → 该目标结算取消，不悬挂。
4. 账本跨回合：回合边界重置生效；觉醒后新代次独立计数。
5. 全部新增逻辑服务器权威（门控）；客户端零裁决。
6. 回归 P2~P5 全绿；既有 `ESkillActivateType` 用例按新标志组合翻译后行为不变。
