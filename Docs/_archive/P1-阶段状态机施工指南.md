## 2. 开工前先修一处：组件的查找路径

`PushPhase` 目前往 **GameMode** 身上找阶段管理器（`GetAuthGameMode()->FindComponentByClass`），而组件实际挂在 **GameState** 上——这条查找永远落空。统一收一个入口：

```cpp
// UBattleGameFlowSubsystem —— 唯一的组件获取入口，其余调用点都走它
UGamePhaseManagerComponent* UBattleGameFlowSubsystem::GetPhaseManager() const
{
    const AGameStateBase* GS = GetWorld() ? GetWorld()->GetGameState() : nullptr;
    return GS ? GS->FindComponentByClass<UGamePhaseManagerComponent>() : nullptr;
}
```

void UBattleGameFlowSubsystem::InitPlayerOrder(int32 StartIndex)

## 4. 阶段修正队列

```cpp
// ArkWarFlowTypes.h（或子系统头内）
enum class EPhaseOpcode : uint8 { Skip, Extra, Jump };

struct FPhaseModifier
{
    EPhaseOpcode Op;
    EGamePhase Target = EGamePhase::GameStart;   // Jump/Extra 使用
};
```

语义约定（对齐三国杀）：

| 操作码 | 含义 | 生效方式 |
|---|---|---|
| `Skip` | 跳过整个大阶段 | 整组吞掉所属大阶段（Pre/主阶段/Post，或 Begin/Finish 独身阶段），落到下一个大阶段的门口；生效时机由 `CanExecute` 判定 |
| `Extra` | 追加一个指定阶段 | 出队时优先返回 `Target`，顺序推进延后 |
| `Jump` | 直接跳至指定阶段 | 出队时立即返回 `Target` |

```cpp
// UBattleGameFlowSubsystem
TArray<FPhaseModifier> PendingModifiers;   // FIFO

EGamePhase UBattleGameFlowSubsystem::ResolveNextPhase(EGamePhase Current)
{
    while (PendingModifiers.Num() > 0)
    {
        const FPhaseModifier Mod = PendingModifiers[0];
        PendingModifiers.RemoveAt(0);

        switch (Mod.Op)
        {
            case EPhaseOpcode::Jump:  return Mod.Target;
            case EPhaseOpcode::Extra: return Mod.Target;   // 顺序推进顺延到下次
            case EPhaseOpcode::Skip:
                Current = NextInSequence(Current);          // 吞掉一步
                break;
        }
    }
    return NextInSequence(Current);
}

// 顺序推进：Begin(1) → … → Finish(17) → GameStart(0)
EGamePhase NextInSequence(EGamePhase Current)
{
    return static_cast<EGamePhase>((static_cast<int32>(Current) + 1) % (GamePhase::PhaseCount + 1));
}
```

P1 只保证队列结构与三个操作码的**最简正确**；谁来塞修正（技能）是 P3 的事，先留好 `PushModifier(...)` 公共接口即可。

## 5. `Advance()`：主轴

```cpp
void UBattleGameFlowSubsystem::Advance()
{
    if (!IsRunningOnServer()) return;

    UGamePhaseManagerComponent* Comp = GetPhaseManager();
    if (!Comp) return;

    EGamePhase Next = ResolveNextPhase(Comp->GetPhase());

    while (true)
    {
        // Finish 之后绕回 GameStart：换人，从 Begin 重新出发
        if (Next == EGamePhase::GameStart)
        {
            Comp->SetNextPlayerActive();
            Next = EGamePhase::Begin;
        }

        Comp->SetPhase(Next);
        UE_LOG(LogGamePlay, Log, TEXT("[GameFlow] Phase entered: %s"), *GamePhase::GetPhaseTag(Next).ToString());

        // P1：_Pre/_Post 空转直通——继续走，直到落在主阶段上停下等待
        if (Next != EGamePhase::Begin && IsPreOrPost(Next))
        {
            Next = NextInSequence(Next);
            continue;
        }
        break;
    }
}
```

要点：

- **停在主阶段**。`Begin/Preparation/Judgment/Draw/Action/Discard/Finish` 是停留点；P1 停留期间什么都不做（没有阶段体逻辑），下一次 `Advance()` 由外部驱动（见第 6 节）。
- `_Pre/_Post` 也会被 `SetPhase`——委托会广播、复制会发生，只是不等待任何响应。等 P3 接窗口时，把 `continue` 换成"开窗等回调"即可，骨架不动。
- `GameStart` 只作为轮转的中转，不作为停留点。

## 6. 启动与驱动入口

```cpp
// UBattleGameFlowSubsystem —— 对局开始时的唯一入口
void UBattleGameFlowSubsystem::StartTurnCycle()
{
    if (!IsRunningOnServer()) return;
    if (UGamePhaseManagerComponent* Comp = GetPhaseManager())
    {
        Comp->SetPhase(EGamePhase::Begin);
        UE_LOG(LogGamePlay, Log, TEXT("[GameFlow] Turn cycle started"));
    }
}
```

- `ABattleGameMode`（或身份分配完成后的流程收尾处）：`InitPlayerOrder(Start)` → `StartTurnCycle()`。
- `PushPhase(Msg)` 保留为**调试/测试驱动**：空串 = 推进一步（把现有雏形的组件查找改为 `GetPhaseManager()` 即可）；`Msg` 分支留给 P3 的修正指令。

## 7. 验收方式

1. **手动逐步**：服务器侧调 `PushPhase("")`（控制台命令或调试按键皆可），目送日志走过
   `Begin → Preparation → Judgment → Draw → Action → Discard → Finish →（换人）Begin`，
   确认 `ActivePlayerIndex` 每轮 +1 且客户端 OnRep 收到。
2. **自动巡转**：临时挂一个 `FTimerHandle`，每秒 `Advance()` 一次，观察整局不间断轮转、换人正确；验毕拆除。
3. **修正冒烟**：手动塞一条 `Skip` 再 `Advance()`，确认跳过了一个阶段；`Jump` 同理。
4. 日志一律英文（现有 `LogGamePlay` 类别），阶段名从 `GetPhaseTag` 取，勿硬编码。
